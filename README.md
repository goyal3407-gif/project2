# Loome — Cotton Scarf Shop

A landing page for "Loome", a cotton scarf shop, built with plain HTML and CSS. New collection hero, colour picker, product details, price and rating, a benefits strip and a bento-style image grid.

## Features

- Shop landing page with product details, colours and pricing
- Benefits strip (organic, lightweight, handmade, secure payment, free shipping, easy returns)
- Responsive layout (includes mobile breakpoints down to 360px)

## Tech

HTML · CSS

## Run it

Open `index.html` in any browser, or use a static server:

```bash
npx serve .
```
